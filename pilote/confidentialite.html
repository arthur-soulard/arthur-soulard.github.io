Pilote, application pour Windows et Mac

Politique de confidentialité

Mise à jour le 2 novembre 2026

En résumé

Pilote ne collecte aucune donnée. Il n'a ni compte, ni serveur, ni publicité, ni mesure d'audience : tout ce que vous saisissez reste sur votre ordinateur, et personne d'autre que vous n'y a accès, pas même l'auteur de l'application.

Où vivent vos données

Vos comptes, vos opérations, vos séances de sport, vos mesures de santé et vos réglages sont enregistrés dans des fichiers sur votre ordinateur :

  • version Microsoft Store : C:\Users\<votre nom>\Pilote\Donnees ;
  • version téléchargée sur GitHub : le dossier Donnees à côté de l'application ;
  • Mac : ~/Library/Application Support/Pilote/Donnees.

Ils ne sont envoyés nulle part. Désinstaller Pilote ne les efface pas : vous pouvez les supprimer vous-même en effaçant ce dossier.

Ce que Pilote demande à Internet

Pour afficher des informations publiques, Pilote interroge directement ces services depuis votre ordinateur :

  • Cours de bourse : Yahoo Finance et Euronext reçoivent les codes des titres dont vous suivez le cours (par exemple WPEA.PA), jamais vos montants ni vos quantités.
  • Composition des ETF : justETF, iShares et Amundi reçoivent l'identifiant (ISIN) des fonds concernés.
  • Mises à jour : la version téléchargée sur GitHub vérifie sur GitHub s'il existe une nouvelle version. La version Microsoft Store est mise à jour par le Store.

Comme pour toute page web, ces services voient l'adresse IP de votre connexion. Pilote ne leur transmet aucun identifiant ni aucune information personnelle.

Deux connexions que vous choisissez

Ces deux fonctions sont éteintes tant que vous ne les réglez pas vous-même :

  • Actus (Gmail) : Pilote lit la boîte Gmail que vous indiquez, pour afficher vos lettres d'information. Il ne l'utilise que pour la lire et n'y envoie rien.
  • Agenda (iCloud) : Pilote écrit dans votre agenda iCloud les notes et rappels que vous lui demandez, et lit vos autres agendas pour les afficher sans les modifier. Si vous réglez la notification « Bilan de la semaine », elle contient un résumé de vos comptes, de vos dépenses et de votre poids.

Les codes d'accès de ces services sont chiffrés sur votre ordinateur par le système (Windows ou le Trousseau du Mac). Les échanges se font directement entre votre ordinateur et Google ou Apple, selon leurs propres règles de confidentialité.

Sauvegardes

Si vous activez la sauvegarde, Pilote copie vos fichiers sur la clé USB ou dans le dossier que vous choisissez. Si ce dossier est synchronisé par un service en ligne (Google Drive, iCloud Drive, OneDrive), c'est ce service, et non Pilote, qui envoie les fichiers.
